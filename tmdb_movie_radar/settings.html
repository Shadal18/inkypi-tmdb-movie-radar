🎬 TMDb Movie Radar

Feature a fresh movie release on your InkyPi display.

Choose upcoming, now-playing, popular, or top-rated movies from TMDb. Configure the region, language, selection behavior, and filters for a poster-first e-paper movie display.

🔑

TMDb API key setup

Create or sign in to your TMDb account, then open Profile → Settings → API. If prompted, choose the free Developer Plan and complete the application form.

For a personal InkyPi setup, use InkyPi TMDb Movie Radar as the application name, http://localhost as the application URL, Desktop Application as the type of use, and describe it as a personal, non-commercial e-paper movie display.

After subscribing, return to Settings → API. Copy the shorter value under API Key, not the long API Read Access Token. In InkyPi's API Keys page, save that value under the exact name TMDB_API_KEY.

Need the TMDb API page? Open TMDb API settings.

🎞️

Movie source

Select the type of TMDb movie list and its regional metadata.

Upcoming and now playing use the selected release region.

Daily pick stays consistent for the same day, mode, and region.

Use a two-letter country code, such as US, CA, GB, or AU.

Use a TMDb language code, such as en-US, fr-FR, or de-DE.

⚙️

Filters and network

Limit which movies can be shown and control TMDb request timing.

Set to 0 to include every movie returned by the selected TMDb list.

Higher values help avoid titles with only a small number of ratings.

Increase this if poster downloads or TMDb requests are slow on your network.
